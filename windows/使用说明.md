# Nyx · 使用说明

## 这个文件夹里有什么

```
Nyx/
├── Nyx.exe          ← 双击这个开软件
├── data/            ← 你的全部学习数据。备份就是复制这个文件夹
│   ├── nyx.db          数据库
│   ├── backups/        自动备份，保留最近 10 份
│   ├── logs/           日志。出问题时把 nyx.log 发给 Claude Code
│   └── audio/          朗读缓存
├── dicts/           ← 词典放这里（见下）
├── prompts/         ← AI 的提示词，用记事本就能改
└── 使用说明.md       ← 就是本文件
```

**整个文件夹拷走就是完整迁移。** 换电脑、换硬盘，拷过去双击就能接着用。

**不要放进 `C:\Program Files`。** 那个目录默认不可写，软件会打不开 ——
放 `D:\Nyx` 这种位置就行。

## 第一次用

1. 双击 `Nyx.exe`
2. 左边点「设置」→「AI」，把你的 API key 贴进去，点保存，再点「测试连接」
   - key 只存在这台机器上，加密保存，不上传、不参与同步
3. 回首页，点「开始」，贴一篇英文材料进去
4. 点「分析」，等它拆完
5. 点「这批我看过了 · 开始学」

## 放词典（可选）

把 StarDict 词典的那一组文件连**整个文件夹**拷进 `dicts/`：

```
dicts/
└── 牛津高阶/
    ├── 牛津高阶.ifo
    ├── 牛津高阶.idx
    └── 牛津高阶.dict     （或 .dict.dz）
```

然后在软件里：设置 →「词典」→「重新扫描」。

没有词典也照常用 —— 例句改由 AI 生成，并且会标明是 AI 生成的。

## 出问题了怎么办

1. 设置 →「数据」→「打开日志文件夹」
2. 打开 `nyx.log`，把**最后几十行**复制下来
3. 连同「我当时在点什么」一起发给 Claude Code

没有日志的话，谁也不知道发生了什么。

## 数据会不会丢

- 每次启动自动备份一次，升级数据库结构之前**再备份一次**
- 备份保留最近 10 份，都在 `data/backups/`
- 升级中途出任何问题，会自动恢复成升级前的样子，并弹窗告诉你备份在哪
- 想自己另存一份：设置 →「数据」→「导出完整备份」，那个 `.db` 文件可以原样导回

**导回是覆盖，不是合并。** 导回之前软件会自动把当前这份备份下来，所以反悔得回去。
